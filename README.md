# 水世界牌 · 独立人机对战

[直接试玩](https://whyuds.github.io/waterworld-card-duel/) · [发牌研究](research/card-deal-study-454-20261008.json)

完整可构建源码，直接克隆此仓库即可运行。不需要水世界助手、Python、游戏账号、登录、数据库、后台服务或私有资源下载。React/TypeScript 界面、规则与 AI、Worker、36 张卡牌与 9 个战场配置、使用到的 58 张原生图片均随仓库提供。浏览器本地计算，不上传手牌、对局或统计；无真人联机。

## 运行

安装 Node.js 22.12+（22 系列）、24 或 26，然后：

```sh
npm ci
npm run dev
```

打开终端显示的本地网址。制作静态网页：

```sh
npm test
npm run build
npm run preview
```

`dist/` 可以部署到任意静态网站服务器。GitHub Actions 每次 main 更新先测试、构建，再发布到当前 GitHub Pages 网址。`public/` 保留旧版已发布的哈希资源，以便正在进行的旧牌局继续取得所需图片和 Worker。

## 游戏与 AI

六回合、三处依次开放的战場、同时选择与安排、共享 36 张牌池、手牌上限 5、每处每方 4 格。各自只取得一张候选；未选候选释放，已取得英雄不能再次取得。AI 用公开观察采样未知手牌和未来发牌，不读玩家真实私牌；支持不同思考时长。

原生大卡面、战场、牌背、能量和战力图标；揭示、弹道、命中、战力变化、移动、移除与沉默逐步播放。选牌浮窗可拖动、透明显示后方战场。部分结算、同分胜者与时序仍是近似，不是官方服务器完整复刻，也没有已经验证的 90% 三星胜率。

## 发牌模型 V8

`snap-36-search-v8-shared-deal` / `round-cost-v2`。

从已有的 454 局完整官方回执还原 2724 回合：免费试玩 101 局、券人机 353 局。按账号和模式留出各自较晚的整局，训练 368 局、留出 86 局，比较均匀、旧 V7、按回合与按实际能量、按费用组与按单牌权重模型。新按回合费用组模型留出负对数似然 2.8164，旧 V7 为 2.8337；改进 0.0173，整局自助法描述性 95% 区间 0.0094～0.0252。比较后区间不能当成新的前瞻验证。

## 文件

- `src/card-engine.ts`：独立规则、共享发牌、隐藏观察、AI 搜索；所有计算无网络。
- `src/card-worker.ts`：浏览器计算 Worker。
- `src/CardDuel.tsx`、`DuelCard.tsx`、`DuelEffects.tsx`：交互和展示。
- `src/card-config.json`、`card-art/`：公开玩法配置与使用到的素材。
- `src/*.test.*`：56 项离线测试，包含共享牌池、私牌隔离、合法动作及展示不改变结算。
- `source.json`：上游基线与逐文件哈希，便于确认同步来源；此项目可独立修改和构建。
