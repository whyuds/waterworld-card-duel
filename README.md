# 水世界牌 · 挑战 AI

[直接试玩](https://whyuds.github.io/waterworld-card-duel/)

基于《疯狂水世界》卡牌玩法的非官方人机小游戏。打开网页即可与 AI 对战，不需要游戏账号；对局在浏览器本地运行，支持电脑和手机。

## 怎么玩

- 一局六回合，共三个战场，依次在第1、2、3回合开放，各有不同效果。
- 每回合从三张候选牌中选一张加入手牌。手牌最多五张，满手牌时跳过选牌；未打出的牌可以留到以后。
- 出牌需要能量，基础能量随回合从1增加到6，部分技能会额外增加能量。双方共用36张英雄牌池。
- 拖动手牌到战场，或点选手牌后点击空位。每个战场每方最多四张牌，双方结束回合后依先手顺序揭示并触发技能。
- 六回合结束时比较战场战力，赢下至少两处即可获胜；三处全胜为三星。点击卡牌详情和战场可查看效果。

AI 默认每回合思考15秒，可在新局开始时调整为1.5～30秒。选牌浮窗可拖动；终局支持再战、同一开局再挑战和保存复盘。

## 与官方有什么不同

使用游戏的卡牌、战场配置和原生图片，展示揭示、战力变化、移动、移除等技能效果。发牌、部分技能组合、效果时序和同战力裁决仍有近似，与官方服务器可能不同。

这里的 AI 是独立搜索程序：根据自己的手牌和公开战场推演，争取三战场全胜，不读取玩家隐藏手牌或本回合安排。官方 AI 的完整算法未知，两者的出牌策略不会完全相同。

本地提供揭示前撤回、调整出牌顺序及不设回合限时的便捷操作；只支持人与 AI 对战，没有游戏内奖励或真人联机。

## 对官方 AI 的胜率

**当前 V8 尚无实测胜率。** 已有直接对战记录来自旧版 V4：2026-10-04，每回合思考15秒，对官方免费试玩 AI 独立复测16局。

|版本|普通胜率|三战场全胜率|
|---|---:|---:|
|旧版 V4|15胜、1负：93.8%|8/16：50.0%|
|当前 V8|尚未实测|尚未实测|

普通获胜与三星不同；旧版样本较少，不能代表当前版本或长期胜率。

## 本地运行

安装 Node.js 22.12+（22系列）、24或26后：

```sh
npm ci
npm run dev
```

打开终端显示的网址。`npm test` 运行测试，`npm run build` 生成可部署的静态网页，`npm run preview` 本地预览构建结果。
